# SHOPLINE

> SHOPLINE is an all-in-one commerce platform for online stores, social commerce, and offline point-of-sale, serving merchants from entrepreneurs to global brands across Asia-Pacific, Europe, and North America. The SHOPLINE Open Platform lets developers build apps, themes, and integrations against a versioned Admin REST API, Admin GraphQL API, and Storefront API.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public SHOPLINE developer documentation; SHOPLINE does not publish its own llms.txt.

## APIs
- [Admin REST API](https://developer.shopline.com/docs/apps/api-instructions-for-use/rest-admin-api/overview): Versioned REST access to store data at https://{handle}.myshopline.com/admin/openapi/{version}/{endpoint}.json
- [Admin GraphQL API](https://developer.shopline.com/docs/admin-graph-ql-api/schema-documentation): GraphQL access to store data
- [Storefront API](https://developer.shopline.com/docs/storefront-api/schema-documentation): GraphQL storefront data at /storefront/graph/{version}/graphql.json
- [Ajax API](https://developer.shopline.com/docs/ajax-api/cookie-consent): Unversioned browser-side storefront API
- [Webhooks](https://developer.shopline.com/docs/apps/api-instructions-for-use/webhooks/overview): HMAC-SHA256 signed event notifications

## Authentication
- [Store authorization overview](https://developer.shopline.com/docs/apps/api-instructions-for-use/rest-admin-api/overview): OAuth 2.0 for Custom/Public apps (Bearer JWT, 10h token + refresh); Private-app tokens for single-store use
- [Access scopes](https://developer.shopline.com/docs/apps/api-instructions-for-use/access-scope): read_*/write_* scope reference

## Developer tools
- [SHOPLINE CLI](https://developer.shopline.com/docs/apps/development-tool/shopline-cli/build-apps-using-shopline-cli): scaffold, run, debug, and deploy apps (npm create @shoplinedev/app@next)
